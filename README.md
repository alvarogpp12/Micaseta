# Micaseta

Plataforma de gestión de club/venue operada 100% por WhatsApp.

Socios invitan amigos con restricciones (días, montos, personas), los invitados
reciben un QR ligado a su teléfono + foto de rostro, y el personal (Puerta y
Mesero) valida accesos y consumos escaneando ese QR. Todo queda registrado para
reportes por socio e invitado.
